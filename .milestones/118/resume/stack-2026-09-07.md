## Three things that cost hours today — do not rediscover them

**A rebase of the stack floor silently stops CI on everything above it.**
Duplicated commits make the upper PR `CONFLICTING`; GitHub cannot compute
`refs/pull/N/merge` for a conflicting PR, so **no run object is created at
all** — not queued, not failed, *absent*. The symptom is an empty check list,
not a red mark. `mergeable` is therefore part of readiness and is checked
alongside the checks.

**A local `cabal build all` green does not predict CI.** CI builds the nix
derivations with `flags.release = true` → `-O2 -Werror` (`nix/haskell.nix:278`,
and the `release` flag in `cardano-wallet-primitive.cabal`). Local `nix build`
is barred; the legal proxy is
`nix develop --quiet -c cabal build all --ghc-options=-Werror`.

**The census falling is not evidence the paths run.** #5430 would have read 33
with three of its five arms unexercised — the first instantiation of the
warning in #5209's own body, on the first slice to touch it.
